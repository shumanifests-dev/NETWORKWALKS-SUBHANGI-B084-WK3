# W3-PM1 – Password Cracking with John the Ripper (JTR)

## Project Overview

This practical introduces John the Ripper (JTR), a password security auditing tool, and its graphical interface, Johnny.

## Objectives

- Understand password hashing in password-protected PDF files.
- Explore John the Ripper and Johnny.
- Configure Johnny to recognise the John the Ripper installation.
- Understand the role of PDF hashes in password security testing.

## Tools Used

- John the Ripper (JTR)
- Johnny GUI
- Networkwalks-provided sample PDF
- PDF Hash Extractor
- Windows

## Work Completed

- Downloaded and extracted John the Ripper.
- Installed Johnny.
- Configured Johnny with the John the Ripper executable.
- Verified that Johnny detected the JTR installation.
- Extracted the hash from the provided sample PDF.
- Saved the extracted hash locally for the practical.

Screenshots documenting the installation, configuration and hash preparation will be added to the `Evidence` folder.

## Learning Outcome

Gained introductory experience with password hashing, PDF hash formats, and configuring a password security auditing environment.
