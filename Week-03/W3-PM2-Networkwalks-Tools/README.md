# W3-PM2 – Password Cracking with Networkwalks Tools

## Project Overview
This practical introduces password security testing using Networkwalks' Hash Calculator and Password Cracker tools.

## Objectives
- Understand password-protected PDF files.
- Learn how PDF password hashes are extracted.
- Explore Networkwalks' Hash Calculator.
- Understand the workflow of password security testing.
- Verify PDF password protection in a controlled lab environment.

## Tools Used
- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Networkwalks-provided sample PDF
- Windows
- Google Chrome

## Practical Workflow
1. Downloaded the sample password-protected PDF supplied by Networkwalks.
2. Prepared the PDF for hash extraction.
3. Explored the purpose of PDF hash extraction.
4. Studied the role of the Password Cracker in the testing workflow.
5. Reviewed the expected password verification process.

## Learning Outcomes
- Understood the relationship between PDF password protection and password hashes.
- Learned the purpose of hash extraction tools.
